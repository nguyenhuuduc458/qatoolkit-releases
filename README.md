# QA Toolkit downloads

1. Open **[Releases](../../releases/latest)** and download the zip for your computer:
   - `QAToolKit-macOS.zip` for a Mac
   - `QAToolKit-Windows.zip` for Windows
2. Unzip it and open QA Toolkit.
   - **macOS:** right-click `QAToolKit.app` → **Open** the first time (the app is not signed).
   - **Windows:** SmartScreen → **More info** → **Run anyway**.
3. In the app, **How to use QA Toolkit** (bottom of the left side) walks you through a first try.

This repository only holds the builds. Problems with the toolkit go through **Report an issue with QA Toolkit** inside the app.
